## 当前能交付什么

- 78表、545列、106外键的独立建库与结构守卫。已有非空库发现不匹配就停止，不自动ALTER、DROP或搬迁数据。
- 9位学号注册/登录；手机号AES-256-GCM加密存储、加盐摘要查找；注册默认未认证。模拟身份不代表真实学生或手机号归属。
- 打卡主表、菜品/图片子表、历史足迹、四项成就进度；同用户/点位/日期唯一；删除联动手账与图片引用计数。
- 饮食档案与`dietary_restriction`，1忌口、2过敏原分开。
- 手账关联打卡、文字、图片，默认私有。拒绝旧画布字段；模板QC-20未确认，暂留NULL，不自创模板枚举。
- 评价、评分明细、图片、审核前状态、三个层级逐维度汇总；只有已发布且未软删评价参与统计。必评口味/份量，其余按就餐方式适用。
- 收藏采用1点位/2档口/3菜品/4帖子；评价点赞采用biz_type=1；重复操作防重、软删后可重新收藏/点赞。
- 宠物初态、喂食、扣款流水；每日任务凭实际当天数据领取；同一用户的奖励与扣款串行化，防止并发重复发钱。宠物等级/外观等未定规则不自行编造。
- 宠物饥饿按规格书6.1.7“连续3天未发布有效点评或打卡”派生；点亮天数按3.0范式材料的有效打卡日期去重计数，喂食不冒充打卡或增加点亮天数。
- 点位/档口/菜品新增数据维护接口使用`user_role`权限，菜品新增为待审，不默认公开。

## 怎么启动和核验

后端`npm start`、`npm run dev`、`npm run start:db3`均进入`src/index3.js`与`app3.js`，不会运行旧种子、旧自动ALTER、旧后台定时任务。默认库名`dafu_shike`；只有显式启动才连接配置的库。本轮只在自建临时MySQL验证，没有启动常驻应用或真实数据库。

先按`backend/.env.db3.example`设置进程环境。Redis用于图形验证码；不可用时验证码验证失败，注册/登录不会绕过验证码。MinIO用于上传，需另行配置并准备存储桶。示例文件不包含真实凭据。

`npm run start:legacy`仅供旧基线对照；检测到location/rating_detail/check_in就停止，不能对3.0补旧列。旧`backend/Dockerfile`与原六容器编排保留历史，尚未完成整站3.0部署切换；3.0后端另有`backend/Dockerfile.db3`，本轮未构建镜像。

实际回归工具：`backend/tools/verify_db3_services.py`。它创建独占临时MySQL服务、运行真实SQL/Node服务与部分HTTP断言，然后优雅停止并删除自己创建的临时目录。禁止把此脚本改成连接真实库跑测试。
